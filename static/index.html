Máy chủ Windows (Giao thức RDP)

Máy chủ này hiện đang kết nối qua cổng RDP (3389). Giao thức RDP phục vụ truyền tải màn hình đồ họa, không mở kênh đo đạc chỉ số (CPU, RAM, Disk, Network) từ xa.

💡 Lệnh kích hoạt OpenSSH Server (PowerShell Run as Admin): 
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'
New-NetFirewallRule -Name 'OpenSSH-Server' -DisplayName 'OpenSSH Server (sshd)' -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22
Sau khi kích hoạt xong OpenSSH trên máy chủ Windows, bấm 🔄 Thử lại ở góc trên bên phải để bắt đầu theo dõi tự động.
